## E. Final pass (leave 60 minutes)

1. Download each uploaded file back from Moodle and open it. An upload that will
   not open is the most common avoidable failure.
2. Check the PDF page count in the reader, not in Word — Word's count differs from
   the exported PDF.
3. Read the forum posts as a logged-out reader would: is the full text there, or
   only a link?
4. Confirm the video plays in the browser preview without downloading.
5. Screenshot each confirmation (post + upload) into `docs/reports/` so that a
   late dispute can be answered.
6. Tag the repository `submission-v1` so the submitted state is reproducible.
